# My Reset V7

V7 behou die bestaande My Reset-hoofblad, Dagboek, kosbeplanner, oefenvideo’s en slim weekverslag.

Belangrik: V7 het ’n unieke PWA-identiteit (`id`) en nuwe service-worker cache sodat die nuwe installasie nie met die vorige geïnstalleerde weergawe verwar word nie.

Dagboekdata word plaaslik op die toestel/blaaier gestoor.
